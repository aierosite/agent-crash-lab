نسخهٔ کامل محلی Agent Crash Lab، نسخهٔ محصول ۰٫۳٫۰

روی Start Crash Lab.cmd دوبار کلیک کنید؛ یا python -I -S launch.py را اجرا کنید. Python 3.12 یا جدیدتر کافی است. هسته و رابط کتابخانهٔ بیرونی، API key، کیف پول یا هزینه نمی‌خواهند. پنجرهٔ ترمینال را باز نگه دارید؛ Ctrl+C سرور همین برنامه را می‌بندد.

تفاوت با هستهٔ اولیه: رابط تعاملی واقعی، هشت سناریو، ورود/خروج دادهٔ دقیق و گزارش، نمایش رسیدها، فرمان CI و آزمایش تازهٔ crash/restart اضافه شده‌اند. هستهٔ اولیه و ZIP آن جدا و تغییرنکرده حفظ شده‌اند.

نمونهٔ اصلی از اجرای تازهٔ واقعی دو شبکهٔ محلی است: worker بعد از نهایی‌شدن پرداخت با کد۷۷ واقعاً متوقف می‌شود و دوباره اجرا می‌شود. روش ساده برای A دوباره پول می‌دهد: ۰٫۲ به‌جای سقف۰٫۱. روش journal تراکنش قبلی را بازیابی می‌کند: A و سفارش مستقلB هرکدام۰٫۱. هر دو روش پاسخ صحیح C03/17 را می‌دهند. این workerها اسکریپت‌اند؛ مدل زنده نیستند. اجرای دمو شبکهٔ تازه یا پرداخت ایجاد نمی‌کند، بلکه ضبط آزمایش را با هسته دوباره ارزیابی می‌کند.

آزمایش تازه مجموعاً پنج ارسال native در دو زنجیرهٔ تازه داشت؛ هر دو گره خاموش شدند. چهار پاسخ HTTP واقعی محلی و مرجع پاسخ از پیش تعیین‌شده بررسی شده‌اند. این کنترل، تضمین تمام خطاهای ممکن یا پرداخت دقیقاًیک‌بار در تولید نیست؛ فقط پنجرهٔ crash مشخص را نشان می‌دهد.

تست‌ها:
python -I -S test_agent_crash_lab.py
python -I -S test_workbench.py
python -I -S verify_reserved.py

۲۶ روش تست هسته + نه روش تست رابط/HTTP/CLI و هشت فراخوانی بررسی رزروشده. تعداد روش تست، سناریو و تراکنش یکی نیست. گزارش اجرای تمیز بسته در verification/release-reproduction.json است. خطاهای اولیه حفظ شده‌اند. برای محدودیت‌های اعتماد README.md و docs/THREAT_MODEL.fa.txt را بخوانید.

هدف طراحی، نسخه‌ای رقابتی و قابل داوری است. هیچ تضمین رتبه، audit امنیت، مدل زنده یا ادعای اولین‌بودن نداریم. مخزن و دمو منتشر شده‌اند و ارسال نهایی مسابقه قبلاً تأیید و ثبت شده است. این نسخه همان پروژه را به‌روزرسانی می‌کند و ارسال تکراری ندارد.

نسخهٔ ۰٫۲٫۳: ده اصلاح محدود بدون قابلیت، وابستگی یا فایل کد تازه. اندازهٔ ۱۹ فایل کد از ۱۷۹٬۶۰۵ به ۱۷۹٬۳۴۶ بایت و از ۱٬۹۶۶ به ۱٬۹۵۹ خط کاهش یافت. هستهٔ ارزیابی بدون تغییر است. تداخل ورود فایل، گزارش قدیمی بعد از خطای اجرای جدید و تطبیق هش با کد واقعاً بارگذاری‌شده اصلاح شد؛ پردازش جدول و رسیدها و ساخت گزارش خام بهینه شدند. گزارش اندازه و شواهد اجرا در verification/release-measurements.json و verification/browser-qa.json ثبت شده است.

نسخهٔ ۰٫۳٫۰: مسیر اعتبارسنجی ورودی در HTTP و CI یکسان شد؛ ناسازگاری پذیرش فیلد ناشناخته رفع شد. برای بررسی کامل داوری، python -I -S tools/verify_release.py --judge را اجرا کنید. ابتدا هش فایل‌ها بررسی می‌شود، سپس هر سه مجموعهٔ آزمون اجرا می‌شوند. CI گیت‌هاب همین فرمان را اجرا می‌کند. تب رسیدها فقط هنگام بازشدن ساخته می‌شود. هسته و ضبط native تغییر نکرده‌اند؛ وابستگی تازه‌ای لازم نیست. تعداد فایل‌های کد ۱۹ و حجم آن ۱۷۹٬۰۶۵ بایت است؛ خطوط فیزیکی از ۱٬۹۵۹ به ۱٬۹۷۱ رسیده است. ارسال قبلی مسابقه محفوظ است و ارسال تکراری انجام نمی‌شود.
