تهدید، فرض و خروجی نامطمئن

طرف ضبط‌شده می‌تواند completed/paid، متن پاسخ، مقدار، شماره invoice یا ترتیب مشاهده را غلط بدهد؛ هسته آن‌ها را حکم نهایی نمی‌داند. replay مشاهدات نباید مبلغ را چند برابر کند؛ قصد مستقل هم‌مبلغ نباید حذف شود. تراکنش موفق و خطای child، rollback، partial/pending، refund منحرف یا شکست‌خورده و قرض/ورودی شخص ثالث بررسی‌های جدا دارند.

این نسخه به owner و مرجع کاری و horizon اعلام‌شده و اصالت ضبط آزمایشگاه اعتماد دارد. اگر سازندهٔ owner یا فایل ضبط دروغ بگوید و hash را هم عوض کند، این hash مانع نمی‌شود. بدون احراز امضا و consensus نمی‌توان یک JSON را شاهد مستقل شبکهٔ عمومی دانست. مرجع داده‌ها نیز از یک operator است؛ بررسی‌های دستی استقلال از خروجی agent دارند، نه استقلال سازمانی.

پروفایل finite است: near-sandbox 2.14/protocol88، native NEAR و inventory-gap-first-v1. همهٔ variantهای عمومی پروتکل، تمام قراردادهای توکن، auth/key permissions، reorg، exploit detection، bridge، gas accounting کامل، balance/net loss و workflowهای دلخواه پشتیبانی کامل ندارند. unsupported یا unknown نتیجهٔ امن نیستند. اجرای زیر LIMITS اثبات دفاع در برابر هر DoS نیست؛ برای ورودی واقعاً خصمانه process isolation و سقف RAM/CPU بیرونی اضافه کنید.

۳۱ quota انتخاب مهندسی‌اند؛ تعدادی مرز مثبت/منفی تست شده‌اند، نه تمام ترکیب‌ها. source-informed regression و synthetic mutation از اجرای native، code review، ادعای README رقبا و آزمایش مدل تفکیک شده‌اند. صفر مدل زنده و صفر ارسال شبکهٔ عمومی داشته‌ایم. دادهٔ ضبط‌شده executable نیست؛ آن را اجرا نکنید و به دستورهای احتمالی داخل متن آن اعتماد نکنید.

آزمایش‌های اصلی پیش از reserved exposure اجرا شدند. اولین reserved failure از نوع missing parent بود و حفظ شده؛ اصلاح باعث می‌شود زمینهٔ غایب unknown شود. پاس بعدی پس از اصلاح است. این پروژه audit تولید، تضمین نبود خطا، رتبه‌بندی معتبر guardها یا تضمین برنده‌شدن نیست.
