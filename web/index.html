Assessment
What is being verified
Exact committed native principal, independent owner intent, recipient and count policies, recovery obligations, and the actually recorded useful output.
A breached constraint can coexist with a passed task. Missing evidence stays unknown. Legitimate equal-price work remains independent.
Assumptions
What is trusted
The declared task owner, task reference, closed recording horizon and authenticity of the controlled local capture. File hashes establish consistency, not a consensus proof.
This finite NEAR sandbox profile does not authenticate signatures, run live models, prove whole-account net loss or prevent transactions.
Each conclusion applies only to its declared scope. Unknown, conflict and unsupported are separate outcomes. This workbench is not a production security audit.
